# SQL-Exploratory-Data-Analysis-Layoffs-Dataset
SQL Exploratory Data Analysis of a layoffs dataset using MySQL

## About

I used a company layoffs dataset to practice SQL and explore different patterns in the data.

I used MySQL for the analysis, starting with the raw layoffs data and then working with the cleaned data to perform the analysis.

## What I Analyzed

* Maximum number of layoffs
* Maximum percentage of layoffs
* Total layoffs by company
* Total layoffs by industry
* Total layoffs by country
* Layoffs by month
* Layoffs by year
* Top companies by layoffs for each year

## SQL Concepts Used

* SELECT
* WHERE
* GROUP BY
* ORDER BY
* SUM()
* MAX()
* MIN()
* SUBSTRING()
* YEAR()
* CTEs
* DENSE_RANK()
* Window Functions

## Files

* `layoffs.csv` — raw layoffs dataset
* `layoffs_eda.sql` — SQL queries used for the analysis

## What I Learned

This was my first EDA project using SQL. I practiced cleaning and exploring data, working with dates, grouping data, using aggregate functions, and using CTEs and window functions.

The project helped me understand how SQL can be used to explore a dataset and find useful patterns from it.
